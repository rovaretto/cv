# CV — Emanuele Rovaretto

LaTeX sources for the curriculum vitae.

## Build (Dev Container)

1. Open this folder in VS Code / Cursor.
2. Reopen in Container (Dev Containers).
3. Compile:

```bash
latexmk -pdf main.tex
```

Output: `main.pdf`.

Toggle CV variants in `main.tex` (`isIA`, `isSW`, `isSpace`, `isKiwi`).
